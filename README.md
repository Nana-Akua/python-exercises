# Python Exercises

Working through *Python Workout* (Manning) — 200 exercises, one at a time.
Each folder contains the solution code and a flowchart mapping out the
logic before writing it, as part of building toward hands-on machine
learning engineering skills.

## Structure

Each exercise lives in its own folder: `NNN-exercise-name/`

- `NNN-solution.py` — the working solution
- `NNN-flowchart.svg` — logic flow, planned before coding when applicable

## Core Python Competencies

This repo tracks my progress through *Python Workout* (Manning, 2nd Edition) — 200 exercises covering:

- **Types** — strings, lists, tuples, dictionaries
- **Files**
- **Functions**
- **Functional programming** — comprehensions, generator expressions
- **Modules and packages**
- **Objects**
- **Iterators and generators**

As I complete exercises, I'll map specific solutions back to these competencies (starting around the 50-exercise mark).
